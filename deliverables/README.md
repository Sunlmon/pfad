# 香港鸟类观测记录，1985–2025

![香港鸟类观测记录静态预览](out/hong-kong-bird-records-2025.svg)

## 研究现象

本项目将 1985 至 2025 年香港地区的鸟类观测记录转化为互动可视化。我希望观察不同年份中，鸟类被记录的位置，以及较常被记录的鸟种如何变化。

本项目并不声称展示香港鸟类的真实总体数量，而是展示人类观察者和资料发布机构所记录到的鸟类。每一根羽毛代表一条已缓存的鸟类观测记录；羽毛位置来自原始记录中的经度与纬度。

## 数据来源

鸟类资料来自 [GBIF Occurrence Search API](https://api.gbif.org/v1/occurrence/search?class=Aves&country=HK&year=2025&hasCoordinate=true&hasGeospatialIssue=false&limit=300)。我筛选了鸟纲（`class=Aves`）、香港地区（`country=HK`）、具有可用坐标的记录，并分别取得 1985 至 2025 年的数据。

每一年最多请求 300 条记录。原始 JSON 回应会不经修改地储存在 `data/` 文件夹，文件名为 `gbif-hong-kong-birds-YEAR.json`。因此，在首次下载完成后，即使没有网络，作品仍可读取本地资料并运行。每条记录可能包括科学名称、经度、纬度、观察日期、资料发布者和其他观测资料。

灰色香港地图底图来自[香港政府地方行政区分界资料集](https://data.gov.hk/en-data/dataset/hk-had-json1-hong-kong-administrative-boundaries)。原始边界 JSON 储存为 `data/hong-kong-boundary.geojson`。

## 视觉系统

羽毛的位置由每条鸟类记录的真实经度和纬度决定。香港行政区边界以细灰线绘制在最底层，羽毛则绘制于地图轮廓上方。

右侧颜色表列出整个时期中记录次数最多的 24 种鸟类。每一种鸟在所有年份中都有固定色相。其他鸟种使用低饱和度的灰蓝色，而且不会发光。在同一年中，记录次数较多的重点鸟种会有更高的颜色饱和度；低饱和度羽毛会先被绘制，因此较鲜艳的羽毛会出现在视觉上层。

网页右上方的下拉菜单可选择年份。羽毛带有缓慢的呼吸律动，但其位置始终来自原始观测记录的地理坐标。

## 图像隐藏了什么

观测记录会受到观鸟者活动地点、地点可达性，以及不同机构是否发布资料的影响。因此，羽毛更多不一定代表当地真实鸟类数量更多。本项目每年最多使用 300 条 API 记录，所以它展示的是已缓存的资料样本，而不是所有香港鸟类观测资料。

另外，灰色底图是行政区边界，不是精细海岸线、地形图或鸟类栖息地地图。少数鸟类记录若落在边界外，也可能是原始资料的坐标误差或地理不确定性，而不一定是程序绘制错误。

## 运行方式

```bash
uv run fetch.py
uv run plot.py
```

运行后，在浏览器打开 `site/index.html`，即可选择不同年份并查看互动可视化。
