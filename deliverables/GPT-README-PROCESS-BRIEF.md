## 项目名称与研究现象

项目标题：**香港鸟类观测记录，1985–2025**

项目把 1985 至 2025 年的香港鸟类观测记录转化为互动视觉作品。

项目不是鸟类总体数量或真实种群密度地图；它展示的是由人类观察者和资料发布机构记录、发布到资料库的鸟类观测记录。

每根羽毛代表一条缓存的鸟类观测记录。羽毛的位置由该记录的真实经度和纬度决定。

---

## 鸟类数据

鸟类资料来源：GBIF Occurrence Search API。

资料链接：

```text
https://api.gbif.org/v1/occurrence/search?class=Aves&country=HK&year=2025&hasCoordinate=true&hasGeospatialIssue=false&limit=300
```

筛选逻辑：

- `class=Aves`：鸟纲；
- `country=HK`：香港；
- 年份：1985 至 2025；
- 只保留有经纬度、且没有已知地理空间问题的记录；
- 每年最多请求 300 条 API 记录。

每一年原始 JSON 回应会不经修改地储存为：

```text
data/gbif-hong-kong-birds-YEAR.json
```

原始记录可能包含科学名称、经度、纬度、观察日期、资料发布者和其他观测资料。

重要限制：每年最多 300 条记录，因此这是缓存的资料样本，不是所有香港鸟类观测记录。

## 香港地图底图

灰色地图底图来源：香港政府地方行政区分界资料集。

资料链接：

```text
https://data.gov.hk/en-data/dataset/hk-had-json1-hong-kong-administrative-boundaries
```

原始边界 JSON 会不经修改地储存为：

```text
data/hong-kong-boundary.geojson
```

它是香港行政区边界资料，不是精细海岸线、地形图或鸟类栖息地地图。灰色边界只能作为地理背景，不能被描述成精确海岸线。

## 最终视觉与互动设计

- 深蓝黑背景；
- 香港行政区边界使用细灰线，在所有羽毛的最底层；
- 每根羽毛的地理位置来自 GBIF 记录中的经度与纬度；
- 羽毛是艺术化的弯曲羽轴和分叉羽枝，不是传统散点；
- 网页中没有内部经纬度网格，只保留地图边框与边缘经纬度标记；
- 右侧有固定的“鸟种—颜色”总表；
- 颜色表列出完整时期中记录最多的 24 种鸟；同一种鸟在每个年份中保持相同色相；
- 其他鸟种使用低饱和灰蓝色，而且不发光；
- 在每个选定年份中，记录较多的重点鸟种颜色更饱和；低饱和羽毛先画，高饱和羽毛后画，因此更鲜艳的羽毛在视觉上层；
- 重点鸟种有柔和、低透明度的光晕；
- 羽毛具有慢速呼吸节奏，但地理位置不随动画移动；
- 网页有年份下拉菜单，可选择 1985 至 2025 的具体年份；
- HTML 互动页面输出为：`site/index.html`；
- README 静态预览图输出为：`out/hong-kong-bird-records-2025.svg`。

运行命令：

```bash
uv run fetch.py
uv run plot.py
```

用户应在浏览器中打开：

```text
site/index.html
```

## 必须诚实说明的局限

README 的“图像隐藏了什么”部分必须说明：

- 观察记录更多，不等于当地真实鸟类数量更多；
- 资料会受观鸟者活动地点、地点可达性、观察努力程度和资料发布机构影响；
- 每年只缓存最多 300 条 API 记录；
- 少数记录可能由于原始资料的坐标误差或地理不确定性而落在地图边界外；
- 灰色底图是行政区边界，不是细致海岸线或栖息地范围。

## AI 使用过程：必须如实写入 PROCESS

学生先自行阅读作业要求、Week 03 示例并运行模板，以理解 `fetch.py` 和 `plot.py` 的不同作用。

之后学生将 AI 当作学习伙伴，逐步询问：URL 的作用、原始资料缓存、JSON 资料结构、经纬度到屏幕位置的转换、循环和函数如何处理多条鸟类记录。

学生不是一开始就要求 AI 直接完成作品；先自行选择了鸟类主题、GBIF 资料来源和视觉方向，再逐步使用 AI 学习并完善资料下载、地图边界、互动年份选择、羽毛样式、颜色层级和光晕效果。

学生保留的建议：

1. 每一年缓存一份原始 GBIF JSON；
2. 缓存香港边界 JSON，使作品离线也可运行；
3. 使用固定鸟种颜色表，使同一鸟种跨年份仍可辨认；
4. 使用真实经纬度定位羽毛。

学生拒绝的建议：

1. 把作品描述为鸟类总体数量地图，因为观测记录不等于真实鸟类数量；
2. 让每根羽毛都发同样的光，因为这会掩盖重点鸟种与其他鸟种之间的层级。

最终 AI 协助完善了深色背景、柔和光晕、弯曲羽毛、颜色饱和度排序、灰色边界底图和互动年份选择器。
